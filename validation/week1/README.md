# NERO + Placo 单臂测试记录

测试日期：2026-08-08

## 测试过程

### 离线测试

- 从 ready 邻域随机生成 100 组安全关节角；
- 使用 URDF 正运动学得到 100 个已知可达的 `link7` 目标位姿；
- 每个目标都从另一组当前关节角开始，由 Placo 重新求 IK；
- 对 IK 解检查残差、关节变化、限位、奇异性和五次平滑轨迹；
- 另行输入无效位姿、不可达位姿、越限姿态和全零奇异姿态，检查拒绝逻辑。

### 真机测试

- NERO 以 10% 驱动速度运行；
- 从真实编码器反馈得到锚点，以该锚点生成 30 个同时包含位置和姿态变化的目标；
- 每个目标重复 3 次；每次执行“锚点 → 目标 → 锚点”；
- 每段运动均重新读取真实关节角、使用 Placo 求 IK，并执行五次平滑关节轨迹；
- 共记录 90 次目标运动和 90 次回程。

## 结果说明

- Placo 末端位姿 IK、姿态控制、ROS 2 通信、五次平滑轨迹和 NERO 真机执行链路均已实际运行；
- 30 个目标都包含位置和姿态变化，90 次目标运动及其 90 次回程全部完成；
- IK 求解用时为毫秒级；启动运动的总延迟还包含 ROS 2 调度、驱动、CAN 和编码器检测；
- 测试过程中没有观察到关节解突然翻转、关节越限或碰撞。

## 测量范围

位置和姿态误差由真实关节编码器反馈结合相同 URDF 的正运动学计算，反映模型内的关节跟踪
和重复性，不等同于外部测量设备得到的相机绝对定位误差。碰撞数据来自现场人工观察；当前
软件尚未建立环境碰撞模型。
